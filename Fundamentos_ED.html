1. Fundamentos de programación

Un programa manipula datos mediante instrucciones. Para trabajar con estructuras es necesario interpretar con precisión qué representa cada variable y qué hace cada operación.

Variables

Una variable tiene un tipo, un nombre y un valor.

int edad = 20;
double nota = 4.5;
String nombre = "Laura";
boolean aprobado = true;

nota = 4.5

Operadores

int suma = 8 + 3;
boolean mayor = 10 > 5;
boolean valido = edad >= 18 && aprobado;

Condiciones

if (nota >= 3.0) {
    System.out.println("Aprobado");
} else {
    System.out.println("No aprobado");
}

Repetición

int i = 0;
while (i < 5) {
    System.out.println(i);
    i++;
}

2. Métodos, parámetros y retorno

Las estructuras de datos se implementan mediante operaciones. Por eso es fundamental comprender cómo un método recibe información, procesa datos y devuelve un resultado.

static int mayor(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}

public static void main(String[] args) {
    int resultado = mayor(8, 13);
    System.out.println(resultado);
}
Parámetro
Dato que recibe el método.
Retorno
Resultado que entrega mediante return.
void
Indica que el método no devuelve un valor.
Encapsulación
Permite concentrar una operación en un método reutilizable.
Ejercicio

Escribe un método esPar(int numero) que devuelva true si el número es par y false en caso contrario.

static boolean esPar(int numero) {
    return numero % 2 == 0;
}

3. Arreglos

El arreglo es una referencia fundamental para comprender por qué existen otras formas de organizar datos.

int[] numeros = {10, 20, 30, 40, 50};

System.out.println(numeros[0]); // 10
System.out.println(numeros[3]); // 40
Índice: 0 1 2 3 4 ↓ ↓ ↓ ↓ ↓ Datos: [10] [20] [30] [40] [50]
Índice

La posición comienza en 0.

length

Indica la cantidad de posiciones.

Recorrido

Permite procesar todos los elementos.

Capacidad

Un arreglo creado con un tamaño determinado mantiene esa cantidad de posiciones.

int suma = 0;

for (int i = 0; i < numeros.length; i++) {
    suma += numeros[i];
}

System.out.println(suma);

4. Programación Orientada a Objetos

Las listas enlazadas utilizan objetos llamados nodos. Por eso es necesario interpretar una clase, sus atributos, sus métodos y la creación de objetos.

class Estudiante {
    String nombre;
    double nota;

    Estudiante(String nombre, double nota) {
        this.nombre = nombre;
        this.nota = nota;
    }

    void mostrar() {
        System.out.println(nombre + " - " + nota);
    }
}

Estudiante e1 = new Estudiante("Ana", 4.5);
e1.mostrar();
Clase

Define la estructura y comportamiento de un tipo de objeto.

Objeto

Instancia concreta creada a partir de una clase.

Atributo

Representa información que pertenece al objeto.

Método

Representa una operación que puede realizar el objeto.

Constructor

Se utiliza para inicializar un objeto al crearlo.

this

Hace referencia al objeto actual.

5. Objetos, referencias, new y null

Este concepto es central para comprender cómo se conectan los nodos de una lista enlazada.

Estudiante e1 = new Estudiante("Ana", 4.5);
variable e1 ───────────────► objeto Estudiante nombre = "Ana" nota = 4.5

La variable e1 mantiene una referencia al objeto creado con new. En Java, los objetos se crean dinámicamente y se almacenan en el heap.

Referencia a otro objeto

class Persona {
    String nombre;
    Persona siguiente;
}
p1 ──► [ nombre = "Ana" | siguiente ] ──► [ nombre = "Luis" | siguiente ] ──► null
null significa que una referencia no está apuntando a un objeto. En una lista enlazada, null permite representar, por ejemplo, que no existe un siguiente nodo.

6. Algoritmos: recorrer, buscar y modificar

Una estructura de datos adquiere utilidad cuando existen operaciones para trabajar con la información que contiene.

Búsqueda lineal

int buscado = 30;
boolean encontrado = false;

for (int i = 0; i < numeros.length; i++) {
    if (numeros[i] == buscado) {
        encontrado = true;
        break;
    }
}

System.out.println(encontrado);

Máximo

int mayor = numeros[0];

for (int i = 1; i < numeros.length; i++) {
    if (numeros[i] > mayor) {
        mayor = numeros[i];
    }
}

Eliminar conceptualmente un elemento

En un arreglo, eliminar no significa simplemente hacer que una posición desaparezca. Puede ser necesario desplazar elementos o utilizar otra estrategia. Esta limitación ayuda a comprender por qué existen estructuras con diferentes formas de almacenamiento.

7. Complejidad algorítmica

La complejidad permite expresar cómo cambia el costo de una operación cuando aumenta la cantidad de datos.

O(1)

El número de operaciones no depende directamente del tamaño de la entrada.

System.out.println(numeros[3]);
O(n)

El trabajo crece proporcionalmente con la cantidad de elementos.

for (int i=0; i<n; i++) {
    System.out.println(i);
}
O(n²)

Un recorrido dentro de otro recorrido produce un crecimiento cuadrático típico.

for (int i=0; i<n; i++)
    for (int j=0; j<n; j++)
        System.out.println(i+j);
SituaciónComplejidad típica
Acceso directo a una posición de arregloO(1)
Recorrer todos los elementosO(n)
Buscar linealmente un valorO(n)
Dos recorridos anidadosO(n²)

8. Tipo Abstracto de Datos (TAD)

Un TAD define qué operaciones ofrece una estructura, sin especificar cómo están implementadas internamente.

TAD: PILA ┌────────────────────┐ │ apilar(x) │ │ desapilar() │ │ ver_tope() │ └────────────────────┘ │ ┌──────┴──────┐ ▼ ▼ arreglo lista enlazada

Una pila presenta comportamiento LIFO: el último elemento que entra es el primero que sale. Su implementación puede utilizar un arreglo o una lista enlazada. La interfaz puede mantenerse aunque cambie la implementación interna.

Interfaz

Operaciones que puede utilizar quien trabaja con el TAD.

Implementación

Forma concreta en que esas operaciones se construyen.

Abstracción

Permite trabajar con el comportamiento sin depender de los detalles internos.

9. De los arreglos a las listas enlazadas

Una lista enlazada utiliza nodos conectados mediante referencias. Su tamaño puede crecer o disminuir creando o eliminando nodos durante la ejecución.

class Nodo {
    int dato;
    Nodo siguiente;

    Nodo(int dato) {
        this.dato = dato;
        this.siguiente = null;
    }
}
cabeza │ ▼ [10 | •] ──► [20 | •] ──► [30 | null]
ConceptoArregloLista enlazada
Acceso por índiceDirectoSe recorren referencias
TamañoFijado al crear el arregloPuede crecer o disminuir
OrganizaciónPosiciones consecutivasNodos conectados mediante referencias
Elemento básicoDatoDato + referencia

Operaciones fundamentales

Insertar al inicio — O(1)
Nodo nuevo = new Nodo(valor);
nuevo.siguiente = cabeza;
cabeza = nuevo;
Recorrer — O(n)
Nodo actual = cabeza;
while (actual != null) {
    System.out.println(actual.dato);
    actual = actual.siguiente;
}
Insertar al final — O(n)

Se recorre la lista hasta encontrar el último nodo.

Eliminar un valor — O(n)

Se localiza el nodo y se modifican las referencias necesarias.

10. Reto integrador

Construye mentalmente la solución antes de escribirla. El problema combina variables, arreglos, ciclos, métodos y objetos.

Problema

Crear un programa que almacene cinco números en un arreglo y tenga métodos para:

  • mostrar todos los números;
  • calcular la suma;
  • encontrar el mayor;
  • buscar un número y devolver true o false.

Solución de referencia

public class Principal {

    static void mostrar(int[] numeros) {
        for (int i = 0; i < numeros.length; i++) {
            System.out.println(numeros[i]);
        }
    }

    static int suma(int[] numeros) {
        int total = 0;

        for (int i = 0; i < numeros.length; i++) {
            total += numeros[i];
        }

        return total;
    }

    static int mayor(int[] numeros) {
        int mayor = numeros[0];

        for (int i = 1; i < numeros.length; i++) {
            if (numeros[i] > mayor) {
                mayor = numeros[i];
            }
        }

        return mayor;
    }

    static boolean buscar(int[] numeros, int valor) {
        for (int i = 0; i < numeros.length; i++) {
            if (numeros[i] == valor) {
                return true;
            }
        }

        return false;
    }

    public static void main(String[] args) {

        int[] numeros = {10, 20, 30, 40, 50};

        mostrar(numeros);

        System.out.println("Suma: " + suma(numeros));
        System.out.println("Mayor: " + mayor(numeros));
        System.out.println("¿Existe 30?: " + buscar(numeros, 30));
    }
}
def mostrar(numeros):
    for numero in numeros:
        print(numero)

def suma(numeros):
    total = 0

    for numero in numeros:
        total += numero

    return total

def mayor(numeros):
    mayor_valor = numeros[0]

    for numero in numeros[1:]:
        if numero > mayor_valor:
            mayor_valor = numero

    return mayor_valor

def buscar(numeros, valor):
    for numero in numeros:
        if numero == valor:
            return True

    return False

numeros = [10, 20, 30, 40, 50]

mostrar(numeros)

print("Suma:", suma(numeros))
print("Mayor:", mayor(numeros))
print("¿Existe 30?:", buscar(numeros, 30))
